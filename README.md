# Using Windows Firewall

In this lab, you will learn to use a Windows firewall. A Windows firewall is an application that filters information that comes to your system from the Internet and blocks potentially harmful programs.

> **Original Lab Source**
> 
> This lab was available through:

## Instructions
### STEP 1
From the bottom-left bar, click the WIN16 tab, and then click On/Connect to power on the machine. 
### STEP 2 
On the taskbar, click the Search Windows icon and in the Search Windows textbox, type Windows Firewall and then click on it to open the Windows Firewall window. 
### STEP 3 
In the Windows Firewall window, from the left pane, click Allow an app or feature through Windows Firewall. 
### STEP 4 
In the Allowed apps window, under Allowed apps and features, scroll down and check the Private and Public checkboxes for Windows Media Player and click OK. 
### STEP 5 
In the Windows Firewall window, from the left pane, click Advanced settings. 
### STEP 6 
In the Windows Firewall with Advanced Security window, from the middle pane, scroll down and click Windows Firewall Properties. 
### STEP 7 
In the Windows Firewall with Advanced Security on Local Computer Properties dialog box, under the Logging section, click Customize. 
### STEP 8 
In the Customize Logging Settings for the Domain Profile dialog box, verify that the Size limit (KB) is 4,096 and click OK twice. 
### STEP 9 
Close all windows.
